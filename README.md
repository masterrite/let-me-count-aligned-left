# Word Counter for VS Code

A simple and efficient word and character counter for Visual Studio Code, supporting multiple languages including Chinese and English. This is a fork from [KrabsWong](https://github.com/KrabsWong/let-me-count). The counter's position is now aligned to the left in the status bar.

## Features

- Real-time word and character counting
- Support for multiple languages (Chinese, English)
- Status bar display
- Refresh command
- Accurate counting for mixed language content

## Usage

The word and character count will be displayed in the status bar at the bottom *left* of your VS Code window. The counter updates automatically as you type.

## Supported Languages

- Chinese (Simplified)
- English
